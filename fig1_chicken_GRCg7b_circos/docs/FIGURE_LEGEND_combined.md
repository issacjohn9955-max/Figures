# Suggested legend (combined Fig1 panel) — edit for the manuscript

Genome-wide distribution of reference transposable elements and assembly-derived variation on
chicken GRCg7b, with representative transposable-element architectures. From outside inward:
reference LINE, LTR, SINE and DNA-transposon union coverage (%), SNV discovery density, Jasmine
SV density and extended TE/repeat-variation (TEV) density. All tracks use the same 1 Mb genomic
windows; terminal windows use their actual lengths. The four TE tracks use independent display
axes (32%, 8.2%, 0.23%, 15%); modest within-chromosome smoothing affects visualization only.
SNV density uses a linear display; SV and TEV use log1p displays, in sites per million reference
bases. TEV retains INS/DEL and simple/low-complexity/satellite repeats under the original
extended definition. Small chromosome display angles are enlarged. Coral ideogram blocks denote
approximate GGswu-transferred centromere candidates, including flank-only candidates; block
widths are schematic, and unsupported chromosomes remain unmarked. The right-hand diagrams show
representative architectures for the four annotated reference classes, coloured to match the
corresponding tracks: a CR1-type LINE (5′ UTR–ORF1–ORF2–3′ UTR–terminal repeats, without a
human L1-style poly(A) tail), an ERV-type LTR element with an optional, lineage-dependent Env,
a schematic tRNA-type SINE with an internal Pol III A/B-box promoter, and a TIR-type DNA
transposon. Segments are not drawn to sequence scale and do not represent all annotated families;
the DNA diagram excludes Helitron/RC, which the source project classifies separately.
Assembly-derived discovery is not equivalent to population allele frequency or jointly filtered
genotype density. Z/W discovery provenance and centromere limitations are recorded with the data.
